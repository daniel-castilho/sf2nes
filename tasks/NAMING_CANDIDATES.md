## 1. How to read this inventory

- **ID:** new, unique, sequential identifier (`N-001`…`N-388`) for stable reference.
- **Previous ID:** ID from the preliminary inventory, when it existed. Repeated IDs in the old inventory received the `(duplicate)` mark; `—` indicates there was no previous ID.
- **Previous symbol:** name in the generated source before the batch (`L<bb>_<aaaa>` for automatic code, or Portuguese semantic name).
- **Applied symbol:** current name in `annotations/sf2ne.ann`.
- **Evidence:** summary of the canonical comment and static flow supporting the name; for FamiTone2, the reference is the public v1.15 structure.
- **Confidence:** `HIGH` = role demonstrated by flow/calls or official structure; `MEDIUM` = probable role, but with less confirmation. There is no `LOW` in this batch.
- **Risk:** `Low` on all lines — the change is only label/comment and the ROM remained identical.
- **Decision:** `ACCEPTED` = applied and verified by build/SHA-1.

### 1.1 Corrections to the preliminary inventory

- **`C3F-01`:** the proposed name was `TimerUpdate`; flow reading showed the block defines `FighterFlip`, so the applied name is **`TimerUpdateFlip`**.

- **Duplicate IDs `C3F-04`…`C3F-08`:** eliminated. The old ID remains in the "Previous ID" column with the `(duplicate)` mark, and each line now has a unique `N-xxx`.
- **P2 batch count:** **251** renames applied (not 245). Includes the two projectile reconciliation lines (`DrawFightersProjectile` and `DrawProjectileMetasprite`), which separate the existence test from the drawing itself.

## 4. Applied naming conventions

| Type | Pattern | Examples |
|------|---------|----------|
| Routine | PascalCase, verb + object | `StateCondDispatchLoop`, `DrawProjectile` |
| Internal routine block | `<Routine><Action>` or descriptive suffix | `TimerUpdateFlip`, `PortraitPalCopyLoop` |
| Transition condition | `Cond` + predicate | `CondOpponentNear`, `CondCanGrab` |
| Ryu AI | `RyuAi` + subsystem + action | `RyuAiAntiAirDist2`, `RyuAiOpponentGrounded` |
| FamiTone2 internal | `_FT2` + structural name | `_FT2UpdateTempo`, `_FT2Channel1NewNote` |
| Bank vector | `ResetVector<bb>` / `NmiVector` | `ResetVector37`, `NmiVector` |

Principles: name by demonstrated role; do not assert unproven characteristics; preserve old name in inventory; no mass cosmetic renaming.
